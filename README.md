# Ask Saigon

**The travel chat that knows Ho Chi Minh City.** Paste a TikTok link and get the real place, snap a menu and get it translated, ask whether a price is fair, find food nearby, or plan a whole day. Every answer comes back as structured cards backed by a checked local dataset, so any travel app can embed it.

> Status: early demo for HIST 2026 (Ho Chi Minh City Tourism Innovation Startup Competition). Data covers District 1 and District 3 only.

Documentation is being written. See `docs/` once it lands.
