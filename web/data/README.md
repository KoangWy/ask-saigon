# Data pipeline

The CSV files are the editable source. Empty cells mean information has not been verified. Run `pnpm build-data` from `web/` to validate the files and regenerate `lib/data/generated/*.json`. The generated files are committed for review and are regenerated by the `predev`, `pretest`, and `prebuild` scripts so deployments use the CSVs in the same revision. Validation rejects invalid opening-hours syntax, missing required values, duplicate IDs, and coordinates outside the District 1 and District 3 bounding box.

Prices are in thousands of Vietnamese dong. The current seed is provisional; sources and checked dates appear in each row. Opening hours and prices are left blank when unknown.
